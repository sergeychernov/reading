# Roles

## Technical Co-Founder

Joining the project as a **Technical Co-Founder** (partner), taking end-to-end ownership
of the technical execution and engineering quality. Combines hands-on full-stack delivery with
architecture ownership to ship quickly without compromising testability, maintainability, and
scalability.

### Core responsibilities

- **Hands-on engineering (FE + BE):** personally deliver key critical features.
  - build the core application and backend systems
  - implement key frontend and user experience features
  - develop data pipelines
  - implement API integrations
- **Architecture & technical direction:** define and evolve the target architecture, make pragmatic
  decisions appropriate for the current stage, and manage technical debt.
- **Codebase standards:** establish and enforce engineering standards.
  - define repo structure, coding guidelines, and review rules
  - define Definition of Done and CI quality gates
  - maintain engineering best practices and documentation
- **Speed vs quality balance:** continuously balance rapid delivery while avoiding both
  over-engineering and short-term hacks that become blockers.
  - ensure performance, security, and scalability
  - maintain automated testing and UI quality
- **Quality control:** set a high bar for reliability, observability, and security.
  - write, review, and maintain production code
  - perform code reviews (including contractors)
- **Hiring:** build a high-quality engineering team.
  - run technical interviews

### Relevant background

- Prior experience building and scaling SaaS startups.
- Leadership experience managing large engineering teams (30+ people), including setting processes,
  standards, and delivery rhythm.
